# 阳桥样板段：前景遮挡与动画素材规格（2026-11-13）

> 状态：**规格已定，素材未到**。本文件是给美术的可交付清单，不宣称任何一项已完成。
> 代码侧已准备好：脚底线分段标注（`src/content/walkway.ts` 的 `review` / `foreground` 字段）、
> 前景图层接入点（`ScrollEngine` 的 world 分层）、姿态回退（`resolvePose`）。

## 1. 为什么先做阳桥一段

整卷五张人姿只有关键姿态，桥面又需要栏杆挡住人物下半身，是最容易暴露"扁平长卷"问题的地方。
先在一段（世界 X ≈ **1100–1600**）做完，通过后再按同样规范扩到整卷。

当前脚底线的复核状态（由 `footlineReviewAt()` 返回，可在控制台验证）：

| 世界 X | 段落 | 复核 | 需要前景层 |
|---|---|---|---|
| 70–1020 | 左岸平缓江岸 | checked | 否 |
| 1100–1596 | 阳桥引桥与桥面（冠部 y≈372） | **pending** | **是（桥栏）** |
| 1750–2104 | 第四景平缓江岸 | checked | 否 |

`pending` 的含义：高度是美术临摹标注，尚未与原画逐段比对，且桥栏本应在人物前方遮挡。
在素材到位前，人物会以关键姿态**直接站在桥面上**，没有栏杆遮挡——这是已知缺口，不隐藏。

## 2. 桥栏 / 岸线前景层

| 项 | 规范 |
|---|---|
| 文件 | `public/art/fg-yangbridge.webp` |
| 画布 | **2172 × 724**，与长卷同坐标系，与背景像素 1:1 对齐，禁止缩放或重新构图 |
| 内容 | 只含**应遮挡人物**的前景：栏杆、柱头、桥头石、近岸草木压边；其余完全透明 |
| 格式 | 透明 WebP lossy 可接受（小比例前景细节），**体积预算 ≤ 350 KB** |
| 锚点 | 左上角 (0,0)，直接叠加在 `scene-day/dusk/night` 之上，不改变原画像素 |
| 标注 | 附带 `fg-yangbridge-zones.json`：`{ "worldXStart": 1100, "worldXEnd": 1600, "footlineY": [...] }` |
| 分层兼容 | 若后续要"人物在栏杆后仍可点击"，再补一层 `fg-yangbridge-hitmask.png`（1-bit alpha） |

接入时：前景层加入 world，`zIndex` 高于人物；人物经过 `foreground: true` 段时保持可见但被遮挡。

## 3. 可走区域掩码

| 项 | 规范 |
|---|---|
| 文件 | `public/art/walk-mask.webp`（256 级灰度，白色 = 可走） |
| 画布 | 2172 × 724，与背景同坐标 |
| 内容 | 岸边路面、桥面可站立带、台阶；水面、山体、建筑内部为黑色 |
| 用途 | 替换 `WALKWAY` 的人工折线；读取掩码下沿得到真实脚底高度；阻止走上栏杆或水面 |
| 体积预算 | ≤ 120 KB（灰度可高度压缩） |

缺少掩码时维持现有折线 + `pending` 标注，不虚构"已经贴地"。

## 4. 主角行走逐帧

| 项 | 规范 |
|---|---|
| 帧数 | **左右各 6–8 帧**（当前只有 1 张 `hero-walk.webp`） |
| 画布 | 每帧等尺寸，**脚底锚点严格为 (0.5, 1)**，同一像素高度 |
| 有效身高 | 站立参考高 116 世界像素（正面原图 1536px 高）。**所有姿态与帧共用同一缩放系数** `HERO_SCALE = 116 / 1536 ≈ 0.0755`，不得按"世界高度对齐"逐姿态缩放 |
| 尺寸注意 | 行走/对山歌原图是**宽跨步**构图（809×1413、727×1428），按高度对齐会把人物放大 7–9%。2026-11-13 已改为统一系数，逐帧素材必须沿用 |
| 命名 | `hero-walk-01.webp` … `hero-walk-08.webp`，或 `hero-walk.json` 图集 + `hero-walk.webp` |
| 格式 | 透明 WebP lossless；单帧 ≤ 320 KB |
| 朝向 | 只做朝右一套，朝左由引擎水平翻转（与现有 `facing` 一致） |
| 帧率 | 12 fps 步频，与 `WALK_SPEED`=185 世界像素/秒对齐（≈15.4 px/帧），步幅需匹配以免"滑步" |

## 5. 捕鱼演出（正午，后续素材阶段）

| 资产 | 拆分要求 | 对应状态 |
|---|---|---|
| 鸬鹚 | 水面停留 / 入水 / 水下 / 叼鱼出水 / 回筏 / 休息，各自独立帧 | `surface → dive → underwater → catch → return → rest` |
| 渔人 | 收鱼、递篓、倚筏 | 与 `catch` 帧对齐 |
| 鱼篓、鱼、竹筏 | 前景层与可交接道具分开 | 交接点在筏首，世界坐标需标注 |
| 水面波纹 | 已有矢量涟漪；正式版可换独立 splash 帧 | 复用现有水纹层 |

**当前状态如实标注**：只有整张插画 + 点击水纹，"整图上下晃动"或"几圈水纹"不算捕鱼动画。
