# 画卷站位、透视与遮挡

原画保持 **2172 × 724**。人物和遮罩使用同一世界坐标，都跟随画卷的镜头缩放和平移。

## 站位与人物尺度

- `Place.worldX` 是取景点，`Place.standX` 是人物站点。象鼻山从对岸的石岸观赏；玻璃桥取景时，人物停在桥西侧平台。两处水面均不在可行走范围内。
- `src/content/walkway.ts` 记录从左岸、双塔岸边、阳桥两侧引道到玻璃桥西侧的连续路线（X=510–1798）。脚底 Y 在标注点之间线性插值；阳桥的桥面经过桥冠后逐渐回落，脚底不再沿一条水平线跨过桥拱。
- 沿步道按就近的亭柱、栏杆和建筑开间标定，将站姿参考高度平滑插值在 **32–46 个世界像素**。五张姿态在相同位置共用 `height / 1536` 的缩放系数；跨步姿态保留原图的相对身高。影子与人物共享位置和尺度，随人物一起遮挡。
- 镜头的缩放与人物的世界比例独立；缩放或拖动时，画卷、步道和人物一起移动。人物随行会为人物留出画幅空间，纯观画仍优先对准景物。

## 三时辰前景

`public/art/foreground-mask-{day,dusk,night}.webp` 是对照对应原画制作的透明轮廓，覆盖岸边护栏、阳桥桥栏以及路径前方的部分树干和植物。尺寸 1350 × 150，原点为世界坐标 `(480, 350)`。白昼遮罩由清晨和正午共用。

WebGL / WebGPU 用 PixiJS 的反向 alpha 遮罩裁掉人物和脚底影子被挡住的像素；Canvas 2D 在人物大小的离屏画布上应用同一遮罩。桥栏缝隙和无遮拦处仍可看到人物。遮罩不重画背景，纯观画模式隐藏人物与影子。时辰切换保留当前画卷，等目标画卷可用再过渡，并随主要可见的画卷切换遮罩。单张遮罩加载失败时继续显示可用画卷，并提示未能载入的素材。

轮廓和步道均来自扁平原画的二维标注；花丛和灯晕边缘仍是近似。当前只有单张行走关键姿态，未加入完整逐帧步态或可自由移动的二维碰撞地图。

## 复核

`npm test` 检查步道边界、高度连续性和景点站位；`npm run verify:assets` 检查遮罩尺寸、无损编码、透明度与体积。实机页面的浏览器验证见 [开发、验收和部署](QUALITY.md)。
