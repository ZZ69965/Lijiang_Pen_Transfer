## 清晰度与资源预算

- **禁止降分辨率**：公开展示用三张高清画卷必须保持原幅像素，人物必须保留原始非透明有效像素。
- 默认采用 WebP lossless（逐像素无损），非低质量 lossy WebP。不使用数十 KB 的预览冒充作品。
- 整套运行图片预计约 10MB，适合展示级网站，但弱网加载相对较慢，需显示加载状态。
- 后续若背景扩展到更多场景：可以用单独发布产物、CDN 或 Git LFS 分离源稿与运行资源；无须以 `git push -f` 反复改写 Git 历史。**`push -f` 本身并不会自动压缩已有提交历史**。
- 原稿继续保存在用户项目素材库，仓库中 `public/art/` 提交的是和原稿像素等价的无损展示文件。

## 画卷坐标、步道与遮挡

四个观景取景点按原画世界坐标布置；人物站在连续的岸线与桥面步道上。景物取景点和人物站点分别记录，象鼻山从对岸观看，玻璃桥从桥西岸观看。详情见 [站位、透视与遮挡](GROUNDING.md)。人物沿步道由较大的近景尺度平滑缩小到远景尺度。

三张独立的昼、夕、夜前景遮罩各 1350 × 150，按原画世界坐标 `(480, 350)` 放置，以 alpha 通道遮挡人物和接触影。轮廓按对应原画实描，格栅镂空保留；白昼由清晨与正午共用。运行格式为无损透明 WebP，单张低于 25 KB；[生成脚本](../scripts/make-foreground-masks.py)。
