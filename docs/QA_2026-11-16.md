## 2. 无人机实装验收（本节补的是 Codex 未看到的画面）

入口：山水漫游 → 入夜 → 画中故事 → 夜游漓江 → 欣赏无人机画稿。

- 两图在三个视口都**完整等比可见**，透明背景正确（不是黑矩形）。
- 默认是象山渔舟；逐光而行需手动切换，**不自动轮播**，保留原活动文字与日期。
- 界面常驻注明「用户供图 · 无人机图案概念展示」「主题画稿保留原图活动文字与日期」，
  并说明这是二维画稿，不是实时飞行编队或演出。

### 修掉的两个真实问题

1. **横屏工具条压住路线。** 844×390 下画稿工具条原本居中叠在四景路线正上方。
   现在矮视口把它移到左下角，路线保持居中；实测两块矩形不再相交
   （viewer 右缘 256，路线左缘 262）。
2. **收起后焦点丢失 / 声明被隐藏。** 曾尝试用 `hidden` 收起「画中故事」入口来腾位置，
   导致 Escape 后焦点无处可回、也把「非当前演出」的声明一起藏掉。已撤回：
   入口保留，改为在横屏上移出工具条所在带。

`retry-recovered.png`；机器可读结果 `drones/results.json`。

## 3. 阳桥完整动线（三时辰）

连续走左引道 → 桥冠 → 右侧桥面 → 台阶 → 岸边，三种时辰各走一遍。

### 修掉的问题：脚底站在「栏杆顶」而不是「桥面石层」

`WALKWAY` 里桥冠高度写的是 y=400，那是**栏杆扶手顶部**。96px 高的人物站在那儿，
靴子会掉到前景遮罩下缘（434）之外，于是从桥栏下面露出来。

- 桥面改为石层 y=431（在遮罩内 3px），三时辰都不会露脚。
- 夕照/夜景遮罩的下缘原本有 44% 空洞（白昼只有 24%），按白昼的实心桥面模板补平，
  三张画遮挡面积一致。
- 新增 `window.__lijiangEngine.describeLayers()` 探针，可读出 `heroY`、可见性和
  world 子节点顺序——层序问题现在用数据回答，不靠盯 4 倍放大图猜。

### 一次我自己制造的误判（记录在此，避免下次重犯）

中途截到「脚下有彩色碎片」，我先后误判为遮罩锯齿、渲染顺序、桥面高度，
连改了三次。真相是：那张图拍在人物**还在走**的中途，她当时站在 x≈1700 的
右岸台阶上（那里地面本来就低）。改成「等 `heroY` 稳定在 431 再截图」后，
画面正确。教训：涉及运动状态的问题，先等状态稳定，再判像素。

录屏：`qa/2026-11-15/rec-bridge-walkthrough.mp4`（本机留存，`qa/` 按设计 gitignore）。
