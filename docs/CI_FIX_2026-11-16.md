## 三处根因

### 1. 行为 QA（旧 run 43711378034）

远端脚本写 `const back = fallback.count ? ... : ...`。`fallback.count` 是**方法对象**，
恒为真，所以永远进入降级分支去等一个不存在的按钮。CI 的 WebGL 正常，根本没有降级面板，
于是 25 秒超时。本地 `isVisible()` 修正已推送。

本轮另加一个**真正强制降级**的场景：只在单个 context 内让 `getContext('webgl*')` 返回
null，走真实的初始化失败分支，断言降级面板出现、仍能进入画卷、且不残留 canvas。
没有全局禁用 WebGL 来凑绿。

顺带修了 preview 服务等待：旧循环跑满 80 次就"当成功继续"，现在超时明确 `exit 1`。

### 2. 三维截图 QA（旧 run 43711378032）

`scripts/visual-smoke.mjs:102` 点已删除的 `.scene-finale-link`。改为可访问名走真实入口
「更多 → 卷尾 · 回望象山」。本轮在这条路上又连修三处**我自己引入**的问题：

1. 断言题诗渲染但只等 250ms → 改为等 `.elephant-poem` 出现；
2. 「题诗」停靠点正好是 0.58，也就是 `orbit→poem` 的判据边界 → 用键盘再推进两格到 0.60；
3. strict mode 匹配到两个 `.elephant-poem`（Suspense 占位壳与真实卷尾同时在文档里）→
   作用域收窄到 `.elephant-variant-finale`。

另外：未捕获的页面错误现在**让检查失败**（原来是 warning）；`npm install` ×2 改为 `npm ci`；
触发路径扩到 `src/app|engine|content|styles/**`，避免 UI 改了而视觉脚本没跑。

### 3. Pages（旧 run 43711378020）

日志是 `Found 1 artifact(s)` 紧接着 `No artifacts named "github-pages"` —— 上传成功、
索引还没可见。这是时序竞态，不是没上传（artifact 14160815530 后来在 API 里查得到）。

修复：在上传与 deploy 之间加**有 120 秒截止时间**的索引可见性检查，按当前 run 查
`github-pages` 且断言未过期；超时打印当前 artifact 名单并失败，而不是盲目部署。

## 本轮另一个真实缺陷：favicon 404

新加的"页面错误即失败"断言抓到 `Failed to load resource: 404`。原因是 `index.html` 没声明
图标，浏览器自动请求 `/favicon.ico`，构建里没有这个文件。
修在应用侧（新增 `public/favicon.png` 并在 HTML 声明），不是把断言放宽。
